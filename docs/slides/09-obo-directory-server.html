Step 09

On-Behalf-Of Flow

Calling downstream APIs with user delegation

The Problem

  • We want to look up people in the university directory
  • Microsoft Graph API has the data
  • But Graph requires its own token (different audience)
  • We can't reuse the user's MCP token for Graph calls
  • Solution: exchange the MCP token for a Graph token

On-Behalf-Of Flow

User authenticates → MCP token (api://app/access_as_user)
                          ↓
Directory Server receives MCP token
                          ↓ OBO Exchange
Azure AD returns Graph token (User.Read.All)
                          ↓
Server calls Graph API AS THE USER

Why OBO?

  • Some orgs (like Duke) restrict application permissions
  • OBO uses DELEGATED permissions — user context preserved
  • Audit trail: Graph logs show the actual user, not a service account
  • Principle of least privilege: users see only what they can access

Two App Registrations Required

  • App 1: Financial Server (from Step 07) — already exists
  • App 2: Directory Server — NEW registration
  • Each has its own client ID, secret, and scope
  • The directory app needs Graph permissions

Directory App Setup

  • Register new app: "MCP Directory Server"
  • Expose an API: access_as_user scope
  • Add Graph permissions (DELEGATED):
    • User.Read.All — read all user profiles
    • Directory.Read.All — read directory data
  • Admin consent required — these are org-wide permissions

The Token Exchange

POST https://login.microsoftonline.com/{tenant}/oauth2/v2.0/token

grant_type = urn:ietf:params:oauth:grant-type:jwt-bearer
client_id = <directory-app-id>
client_secret = <directory-app-secret>
assertion = <user's MCP token>
scope = User.Read.All Directory.Read.All
requested_token_use = on_behalf_of

Token Caching

class OBOTokenCache:
    # Thread-safe, TTL + LRU eviction
    # Key: SHA256(user_token)[:32]
    # Value: (graph_token, timestamp, expires_at)
    # Max 500 entries, 50-min TTL

Without caching: OBO exchange on EVERY Graph call.

With caching: once per session.

Graph API Client

class GraphClient:
    async def find_user(self, token, query):
        if "@" in query:
            filter = f"mail eq '{query}'"
        else:
            filter = f"startswith(displayName, '{query}')"
        return await self.get("/users", token,
                              params={"$filter": filter})

PII Sanitization in Logs

def sanitize_for_log(value: str) -> str:
    if "@" in value:
        return f"{value[:2]}***@{value.split('@')[1]}"
    return f"{value[:3]}***"

# "alice@duke.edu" → "al***@duke.edu"

Never log full PII — always sanitize.
