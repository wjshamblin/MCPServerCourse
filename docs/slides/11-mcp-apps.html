MCP Apps

Interactive dashboards inside the conversation

What are MCP Apps?

  • Tools that return interactive HTML UIs rendered in the chat
  • Not separate web apps — they live inside the conversation
  • Sandboxed iframe with bidirectional communication
  • Supported by Claude, Claude Desktop, VS Code Copilot, Goose

Why not just a web app?

  • Context preservation — UI lives in the conversation
  • Bidirectional data flow — app calls server tools
  • Security — sandboxed iframe, no cookie/DOM access
  • No separate auth — uses existing MCP session

Two Approaches in FastMCP

App 2: Grant Portfolio

  • FastMCPApp pattern — separate UI and backend tools
  • @app.ui() — the entry point the LLM calls
  • @app.tool() — backend tools the UI calls via CallTool
  • Click a grant → CallTool(get_grant_detail) → updates state

FastMCPApp Pattern

grant_app = FastMCPApp("GrantPortfolio")

grant_app = FastMCPApp("GrantPortfolio")

@grant_app.tool(model=True)
async def get_grants(sponsor_filter: str = "") -> list[dict]:
    ...  # Query database

@grant_app.ui()
async def grant_portfolio() -> PrefabApp:
    with Column() as view:
        with Form(on_submit=CallTool(
            get_grants,
            arguments={"sponsor_filter": STATE.sponsor_filter},
            on_success=[SetState("grants", RESULT)],
        )):
            Select(name="sponsor_filter", ...)
            Button("Filter")
    initial = await get_grants(status_filter="active")
    return PrefabApp(view=view, state={"grants": initial})

CallTool: UI → Server

User clicks grant card in UI
    → CallTool(get_grant_detail, {grant_id: "NSF-123"})
    → Server executes query
    → SetState("detail", RESULT)
    → UI updates with spending chart + transactions

No page reload. No separate API. MCP handles it.

Adding Duke OIDC Auth

Key Takeaways

  • FastMCPApp with @app.ui() + @app.tool(model=True)
  • Form + Select + CallTool(fn, arguments={...STATE})
  • Use STATE.field_name to pass form values to tools
  • Prefab UI: charts, cards, metrics, progress bars, forms
  • Apps inherit server auth — secure by default
