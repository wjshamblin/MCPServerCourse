Financial Dashboard — Capstone

Everything from the MCP Apps arc, assembled into one real dashboard.

What We Build

  • A four-tab research-admin financial dashboard
  • SQLite-backed (deterministic seed, 4 funds · 4 people · 52 transactions)
  • Six data tools + one UI tool, all on one FastMCPApp
  • Every data tool is model=True — same surface for human and LLM

Two Python files. No npm, no bundling, no React.

Seed the UI at Render Time


@dashboard_app.ui()
async def financial_dashboard() -> PrefabApp:
    initial = _build_initial_state()  # calls the tools directly

    with PrefabApp(title="Financial Dashboard",
                   state=initial, css_class="p-6 max-w-6xl mx-auto"):
        Heading("Financial Projections Dashboard", level=2)

        with Tabs(name="tab", value="overview"):
            with Tab(title="Overview", value="overview"):   _overview_tab()
            with Tab(title="Grants & Funds", value="grants"): _grants_tab()
            with Tab(title="Personnel", value="personnel"):  _personnel_tab()
            with Tab(title="Transactions", value="transactions"): _transactions_tab()

One tree. State is seeded once; tabs switch client-side.

Grants Tab — ForEach over State


def _grants_tab() -> None:
    with Grid(columns=2, gap=4):
        with ForEach("fund_details") as fund:
            _fund_card(fund)          # one template, four cards

def _fund_card(fund):
    with Card(css_class="p-5 space-y-3"):
        CardTitle(f"{fund.name} — {fund.id}")
        with If(fund.utilization_pct):
            Progress(value=fund.utilization_bar, variant="info")
        with If(fund.additional_funding):
            with ForEach(fund.additional_funding) as af:
                Row(gap=2)
                Text(af.period); Text(af.amount_fmt)

One Card template. Four funds → four cards. Reactive, no duplication.

📚 Prefab: ForEach, If, Progress

Transactions — Live CallTool


# Fund filter: changing the Select re-calls get_transactions
Select(name="filter_fund", placeholder="All funds",
       on_change=CallTool(
           get_transactions,
           arguments={"fund_id": STATE.filter_fund,
                      "category": STATE.filter_category,
                      "sort_by": STATE.filter_sort_by,
                      "sort_order": STATE.filter_sort_order},
           on_success=[
               SetState("txn_rows_raw", RESULT["transactions"]),
               SetState("txn_count",    RESULT["count"]),
               SetState("txn_total",    RESULT["total"]),
           ],
       ))

Every filter change is a real MCP round-trip. The LLM can run the same call.

Personnel — Series Built Once


def _personnel_tab() -> None:
    # The BarChart needs one series per fund name; build at open time.
    fund_names = sorted({a["fund_name"]
                         for p in get_personnel()
                         for a in p["allocations"]
                         if a.get("fund_name")})

    BarChart(data=STATE.effort_chart,
             series=[ChartSeries(data_key=n, label=n) for n in fund_names],
             x_axis="name", stacked=True, horizontal=True,
             height=max(240, 60 * len(personnel) + 60))

Python loops at render time produce a concrete series list; the chart is data-driven thereafter.

Same Surface, Two Consumers

Human

  • Opens the dashboard
  • Clicks the Transactions tab
  • Picks a fund from the dropdown
  • Prefab fires CallTool(get_transactions, ...)

LLM

  • Asks "what did we spend on supplies last month against the R01?"
  • Model calls get_transactions(fund_id="501002345", category="LAB SUPPLIES...")
  • Same tool, same result, same code

This is the whole point of model=True.

Key Takeaways

  • A real dashboard fits in two Python files
  • Seed state once at open time; use CallTool only where the UI must talk back to the server
  • ForEach + Rx pipes collapse repetition — one card template, N cards
  • Every tool is callable by both the UI and the LLM — that's the deal you get for making them model=True
  • No build step, no bundler, no JavaScript — FastMCP + Prefab is enough
